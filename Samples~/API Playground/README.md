# RPlay Games API Playground

이 샘플은 RPlay Games Unity SDK의 로그인 및 게임 API 호출 흐름을 확인하기 위한 예제입니다.

`RPlayGamesSettings.asset`에는 바로 실행해 볼 수 있도록 RPlay 테스트 게임의 `GameOid`가 기본으로 들어 있습니다.
실제 게임을 개발하거나 배포할 때에는 이 값을 RPlay 게임 관리 화면에서 확인한 해당 게임의 `GameOid`로 반드시 교체하세요.

API 호출은 운영 환경에 연결됩니다. 저장 데이터, 리더보드, 코인 및 크레딧 소비가 실제 계정에 반영됩니다.
